# 报警-调度外部接口文档（简易版）

> 仅列出外部平台需要对接的接口、入参、出参。

---

## 1. 外部告警接入

| 项 | 内容 |
|---|---|
| 方法 | `POST` |
| 路径 | `/external/suspect/events` |
| 调用方 | 外部平台 |

### 入参

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `source` | string | 是 | 来源：`radar` / `videoAI` / `manual` / `third_party` |
| `alarmType` | string | 是 | 告警类型，如 `border_intrusion` |
| `alarmTime` | string | 是 | ISO-8601 告警时间 |
| `location` | object | 是 | 初始位置 `{ lng: float, lat: float }` |
| `deviceId` | string | 否 | 触发设备 ID |
| `confidence` | float | 否 | 置信度 0~1 |
| `rawData` | object | 否 | 原始 payload |
| `metadata` | object | 否 | 扩展字段 |

### 出参

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | 200 成功 |
| `message` | string | 提示信息 |
| `data.eventId` | string/int | 事件 ID |
| `data.status` | string | 事件状态 |
| `data.isNew` | bool | 是否新建事件 |

---

## 2. 第三方需提供的数据

本系统直接读取第三方数据库表，不通过 REST 接口。

| 表名 | 用途 | 说明 |
|---|---|---|
| `patrol_cameras` | 摄像头分布 | 用于轨迹补全与边境线生成 |
| `special_areas` | 特殊区域 | 禁入区/地形约束（可选） |

### 摄像头表 `patrol_cameras`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string/int | 是 | 摄像头唯一 ID |
| `name` | string | 否 | 名称 |
| `lng` | float | 是 | 经度 |
| `lat` | float | 是 | 纬度 |
| `detection_radius` | float | 否 | 探测半径（米） |
| `type` | string | 否 | 摄像头类型 |

### 特殊区域表 `special_areas`（可选）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string/int | 是 | 区域 ID |
| `name` | string | 否 | 名称 |
| `polygon` | JSON / array | 是 | 多边形顶点 `{lng, lat}` |
| `type` | string | 是 | `restricted` / `terrain` 等 |

> 边境线由 `patrol_cameras` 按位置连接生成，无需单独提供。

---

## 3. 轮询最新调度方案

| 项 | 内容 |
|---|---|
| 方法 | `GET` |
| 路径 | `/dispatch/plan/latest` |
| 调用方 | 外部平台 |

### 入参

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `eventId` | string/int | 是 | 事件 ID |
| `suspectLng` | float | 否 | 嫌疑人最新经度 |
| `suspectLat` | float | 否 | 嫌疑人最新纬度 |
| `taskId` | string | 否 | 链路追踪 ID |

### 出参

| 字段 | 类型 | 说明 |
|---|---|---|
| `planId` | string | plan ID |
| `planVersion` | int | 版本号 |
| `planUpdatedAt` | string | ISO-8601 生成时间 |
| `captureFeasible` | bool | 是否可拦截 |
| `reason` | string | 不可行原因 |
| `targetPoint` | object | `{ lng, lat }` |
| `resources` | array[object] | 调度资源列表 |
| `summary` | object | 调度摘要 |

### resources 单项

| 字段 | 类型 | 说明 |
|---|---|---|
| `resourceId` | string | 资源 ID |
| `resourceName` | string | 资源名称 |
| `type` | string | 资源类型 |
| `action` | string | 动作，如 `intercept` |
| `targetLng` | float | 目标经度 |
| `targetLat` | float | 目标纬度 |
| `etaSeconds` | int | 预计到达时间（秒） |
| `plannedPath` | array[{lng, lat}] | 规划路径 |
| `explanation` | object | 决策解释（见下） |

### explanation

| 字段 | 类型 | 说明 |
|---|---|---|
| `targetDescription` | string | 目标点来源与置信度 |
| `resourceSelectionReason` | string | 资源选择原因 |
| `pathSummary` | string | 路径概览 |
| `constraintsConsidered` | array[string] | 考虑的约束 |

## 4. 确认执行方案

| 项 | 内容 |
|---|---|
| 方法 | `POST` |
| 路径 | `/dispatch/confirm` |
| 调用方 | 外部平台 |

### 入参

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `planId` | string | 是 | 待确认 plan ID |
| `eventId` | string/int | 是 | 事件 ID |
| `confirmedDeviceIds` | array[string] | 是 | 确认参与执行的设备 ID |
| `latestSuspectPos` | object | 是 | `{ lng, lat }` |
| `taskId` | string | 否 | 链路追踪 ID |

### 出参

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | 200 成功 |
| `message` | string | 提示信息 |
| `data.status` | string | `confirmed` / `invalid` / `expired` |
| `data.expectedPoint` | object | `{ lng, lat, confidence }` |
| `data.confirmedDevices` | array[object] | 已确认设备列表 |
| `data.reason` | string | 失败原因 |

---

## 5. 调度智能设备

| 项 | 内容 |
|---|---|
| 方法 | `POST` |
| 路径 | `/dispatch/dispatch` |
| 调用方 | 外部平台 |

### 入参

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `eventId` | string/int | 是 | 事件 ID |
| `latestSuspectPos` | object | 是 | `{ lng, lat }` |
| `planId` | string | 否 | confirmed plan ID |
| `confirmedDeviceIds` | array[string] | 否 | 指定设备，默认沿用已确认设备 |
| `taskId` | string | 否 | 链路追踪 ID |
| `clientRequestId` | string | 否 | 幂等键 |

### 出参

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | 200 成功 |
| `message` | string | 提示信息 |
| `data.dispatchId` | string | 下发 ID |
| `data.status` | string | `dispatched` / `pending` / `failed` |
| `data.targetPoint` | object | `{ lng, lat }` |
| `data.devices` | array[object] | 已下发设备结果 |
| `data.reason` | string | 失败原因 |

### 设备平台调用（本系统内部调用）

| 项 | 内容 |
|---|---|
| 方法 | `POST` |
| URL | `http://192.168.0.33:5284/Remote/send` |

#### 入参

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `requester` | string | 是 | 固定填 `"指挥中心"` |
| `orderType` | int | 是 | 固定填 `1` |
| `deviceID` | string | 是 | 设备平台设备 ID |
| `longitude` | double | 是 | 目标经度 |
| `latitude` | double | 是 | 目标纬度 |
| `elevation` | double | 否 | 高程，默认 `0` |

```text
外部告警接入
    ↓
轮询 /dispatch/plan/latest
    ↓

    ↓
每分钟轮询 /dispatch/dispatch
```
