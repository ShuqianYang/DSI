# 合并远程更新的步骤

> 本文档整理从远程仓库拉取更新并与本地代码合并的标准流程。

## 场景

- 本地已有 Git 仓库，并已添加远程仓库 `origin`。
- 远程分支（如 `agent-loop`）有更新，需要合并到当前本地分支。
- 当前本地分支名为 `master`（如果你的是 `main`，将下文中的 `master` 替换为 `main`）。

## 前置检查

执行前建议先确认：

```bash
# 查看当前分支和未提交修改
git status --short

# 查看已配置的远程仓库
git remote -v

# 查看本地分支
git branch -vv
```

## 完整流程

### 1. 提交或暂存当前本地修改

**推荐先提交**，避免合并时与工作区冲突：

```bash
git add .
git commit -m "wip: border-defense-qa skill before remote merge"
```

如果暂时不想提交，也可以暂存：

```bash
git stash push -m "local changes before merging origin/agent-loop"
```

合并完成后再恢复：

```bash
git stash pop
```

---

### 2. 拉取远程分支

```bash
git fetch origin agent-loop
```

如果你不确定远程有哪些分支，可以先查看：

```bash
git branch -r
```

---

### 3. 合并到本地分支

#### 方式 A：merge（保留分支历史，推荐）

```bash
git merge origin/agent-loop --no-edit
```

`--no-edit` 表示自动生成默认合并提交信息。

#### 方式 B：rebase（线性历史，更干净）

```bash
git rebase origin/agent-loop
```

> 注意：rebase 会改写本地提交历史。如果本地提交已经推送到远程，不建议使用 rebase。

---

### 4. 解决冲突（如果有）

如果合并过程中出现冲突，Git 会提示类似信息：

```text
Auto-merging xxx/xxx.ts
CONFLICT (content): Merge conflict in xxx/xxx.ts
Automatic merge failed; fix conflicts and then commit the result.
```

解决步骤：

```bash
# 1. 查看冲突文件
git status

# 2. 手动编辑冲突文件，保留需要的代码
# 冲突标记格式：
# <<<<<<< HEAD
# 本地代码
# =======
# 远程代码
# >>>>>>> origin/agent-loop

# 3. 标记冲突已解决
git add <冲突文件>

# 4. 继续合并
git merge --continue

# 如果使用 rebase，则执行：
# git rebase --continue
```

---

### 5. 验证合并结果

```bash
# 查看提交历史
git log --oneline --graph -10

# 查看工作区是否干净
git status --short
```

## 常见问题

### Q1：拉取时提示网络超时

错误示例：

```text
Failed to connect to github.com port 443 after 21312 ms: Could not connect to server
```

解决方法：

```bash
# 配置代理（把 7890 换成你的代理端口）
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890

# 或使用 SSH 协议
git remote set-url origin git@github.com:<username>/<repo>.git
```

---

### Q2：本地没有对应远程分支的本地分支

如果你想在本地创建并切换到 `agent-loop` 分支：

```bash
git fetch origin agent-loop
git checkout -b agent-loop origin/agent-loop
```

---

### Q3：想放弃本次合并

如果合并过程中想回到合并前状态：

```bash
# merge 模式下
git merge --abort

# rebase 模式下
git rebase --abort
```

---

## 快捷命令汇总

```bash
# 提交本地修改
git add .
git commit -m "wip: before remote merge"

# 拉取并合并指定远程分支
git fetch origin agent-loop
git merge origin/agent-loop --no-edit

# 解决冲突后继续
git add .
git merge --continue
```
