# `border-defense-qa` Skill 人工测试用例

> 文档编号：12  
> 日期：2026-06-17  
> 适用范围：第五层场景化功能测试（手动验证）

---

## 一、启动项目

### 1. 启动后端

```bash
cd api
pnpm dev
```

后端默认运行在 `http://localhost:3001`（由 `API_PORT=3001` 控制）。

### 2. 启动前端

在另一个终端窗口执行：

```bash
cd D:/0 ysq文件/DSI-agent-loop
pnpm dev
```

前端默认运行在 `http://localhost:3000`。

### 3. 访问界面

打开浏览器，访问 `http://localhost:3000`。

- 使用测试账号登录：用户名 `admin`，密码 `admin123`；
- 进入主界面后，使用左侧或底部的**智能问答面板**输入问题。

---

## 二、如何触发 Skill

直接在智能问答面板中用中文提问。当问题涉及边防数据（预警事件、卡口通行、设备状态、部门、巡逻等）时，Agent 会自动识别并调用 `border-defense-qa` Skill。

---

## 三、测试关注点

每条用例执行后，请检查以下项目：

| 检查项 | 期望结果 |
|--------|----------|
| Skill 调用 | 是否加载 `border-defense-qa` Skill |
| 工具范围 | 仅使用 `Read` / `MysqlQuerySchema` / `MysqlQuery`，无 `Bash` / `Write` |
| SQL 类型 | 仅 `SELECT` / `WITH`，拒绝 DML/DDL |
| 时间范围 | 本月/本周/今天/最近7天等解释正确 |
| 术语区分 | "处理"对应 `handle_xxx`，"处置"对应 `dispose_xxx`，不混淆 |
| 回答格式 | 中文 Markdown，带数据表格和简要分析 |
| 空数据 | 返回"经查询，当前时间范围内暂无相关数据" |
| 无关问题 | 不调用工具，直接返回固定拒绝语 |

## 四、测试用例

### 4.1 基础统计类

| 编号 | 问题 | 预期验证点 |
|------|------|------------|
| 1 | 统计本月各级预警数量 | 按 `event_level_name` 分组统计 |
| 2 | 今天有多少条预警？ | 正确解释"今天"为 00:00 至今 |
| 3 | 最近7天一级预警有多少条？ | 正确解释"最近7天"为 CURRENT_DATE - 7 |
| 4 | 本周各天预警数量趋势 | 正确解释"本周"并按天分组 |
| 5 | 上个月一级预警和二级预警各占多少比例？ | 正确切换至上个月时间范围 |

### 4.2 设备相关

| 编号 | 问题 | 预期验证点 |
|------|------|------------|
| 6 | 在线率最低的设备类型是什么？ | 查询 `tb_device`，关联 `online_status` |
| 7 | 哪个设备产生的预警最多？ | 关联 `alarm_event.device_id` 与 `tb_device.dev_id` |
| 8 | 列出所有离线的设备名称和安装位置 | 过滤 `online_status`，返回 `dev_name`/`install_place` |
| 9 | 某某设备本月触发过几次预警？ | 按设备名过滤并统计 |

### 4.3 部门相关

| 编号 | 问题 | 预期验证点 |
|------|------|------------|
| 10 | 某某部门的预警有多少条？ | JOIN `sys_dept` 按 `dept_name` 过滤 |
| 11 | 各部门预警数量排名 Top 5 | 按 `owner_dept_name` 分组排序 |
| 12 | 某某部门下有多少台设备？ | 关联 `tb_device.dept_id` 与 `sys_dept.dept_id` |

### 4.4 卡口通行

| 编号 | 问题 | 预期验证点 |
|------|------|------------|
| 13 | 今天通过各卡口进入的车辆总数是多少？ | 查询 `buckle_access_record`，`object_category = 2` |
| 14 | 哪个卡口今天车流量最大？ | 按卡口分组并排序 |
| 15 | 列出本周黑名单车辆进入记录 | `buckle_access_list.list_type = 2` 关联 `buckle_access_record` |
| 16 | 白名单人员今天通过了哪些卡口？ | `list_type = 1` 且 `object_category = 1` |
| 17 | 某某卡口当前有多少条滞留记录？ | 查询 `buckle_retention`，`data_type = 2` |

### 4.5 处理/处置语义区分

| 编号 | 问题 | 预期验证点 |
|------|------|------------|
| 18 | 平均处理时长是多少分钟？ | 使用 `handle_time - event_time`，不是 `dispose_time` |
| 19 | 已处置的预警有多少条？ | 使用 `dispose_status = 2` |
| 20 | 平均处置时长是多少？ | 使用 `dispose_seconds` |

### 4.6 空数据与边界

| 编号 | 问题 | 预期验证点 |
|------|------|------------|
| 21 | 1900年的预警有多少条？ | 返回"经查询，当前时间范围内暂无相关数据" |
| 22 | 查询火星基地的预警有多少条？ | 不应编造数据，应说明无数据 |

### 4.7 特殊响应

| 编号 | 问题 | 预期验证点 |

| 23 | 你是谁 | 不调用工具，返回固定自我介绍 |

### 4.8 安全类（验证 SQL 拦截）

## 六、附录：固定回复文案

### 自我介绍

> 您好，我是边防智能问答助手，专注于边防数据的智能分析与问答。我可以帮您：
> 1. **数据查询**：查询预警事件、设备状态、人员/车辆通行记录、大门往来等信息；
> 2. **统计分析**：对边防数据进行多维度统计，如预警分级统计、设备在线率分析、通行流量统计、处理时效分析等；
> 3. **趋势分析**：分析特定时间段内的数据变化趋势，识别异常时段和高风险区域；
> 4. **可视化展示**：根据查询结果自动生成柱状图、折线图、饼图等图表，辅助分析决策；
> 5. **明细查询**：查看预警事件、设备、大门、部门等详细信息及其地理位置（经纬度）。
> 请直接告诉我您想了解哪些边防数据，我会为您查询并分析。

### 无关问题拒绝语

> 抱歉，我只能回答与数据库中预警事件、大门通行记录、设备信息等相关的问题。请尝试询问如'最近一周的一级预警有多少？'或'查询所有白名单车辆记录'等。
